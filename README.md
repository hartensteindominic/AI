# FutureSelf

A futuristic web app for building a personal AI "Mini-Me" and exploring simulated 7-day futures.

## MVP
- Create a Mini-Me profile
- Define goals, routine, and decision style
- Run a 7-day scenario simulation
- Compare possible outcomes
- View an actionable future report

## Product principle
FutureSelf does not claim to literally predict the future. It generates probabilistic scenarios from the user's supplied information and makes uncertainty visible.
